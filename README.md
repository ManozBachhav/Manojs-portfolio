#  Manoj Bachhav — Portfolio

A personal portfolio website showcasing my skills, projects, and experience as a Full Stack Developer.

🌐 **Live Site:** [manojsbachhav.vercel.app](https://manojsbachhav.vercel.app/)

---

##  About

I'm Manoj Bachhav, a Full Stack Developer specializing in building scalable and impactful applications. I have hands-on experience with modern technologies across frontend, backend, and cloud environments.

---

##  Features

- Animated hero section with typing effect
- Skills section organized by category (Languages, Frontend, Backend, Database, DevOps & Tools)
- Projects showcase with live previews
- Experience & Education timeline
- Contact section with social links
- Fully responsive — works on all screen sizes
- Smooth scroll animations using AOS

---

##  Tech Stack

**Frontend**
- React.js
- SCSS
- Vite

**Libraries**
- AOS (Animate On Scroll)
- react-type-animation
- Three.js (background effects)

**Deployment**
- Vercel

##  Getting Started

### Prerequisites
- Node.js (v16+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/ManozBachhav/Manojs-portfolio.git

# Navigate into the project
cd Manojs-portfolio

# Install dependencies
npm install

# Start the dev server
npm run dev
```

The app will run at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
